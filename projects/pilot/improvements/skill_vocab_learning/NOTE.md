# Skill Improvement Note: Handling Transcript Annotations

When running vocabulary extraction or parsing transcripts, look out for metadata and non-lyric audio annotations. These are typically generated by speech-to-text engines or subtitle files and do not form part of the actual song lyrics or text content.

## General Pattern
Annotations are typically wrapped in:
- Parentheses: `(gentle music)`, `(children laughing)`
- Square brackets: `[Narrator]`, `[cheering]`

## Recommendation
Before processing the text through the vocabulary learning design parser, strip out lines or text segments matching these patterns to ensure that only the spoken/sung lyrics are analyzed.
